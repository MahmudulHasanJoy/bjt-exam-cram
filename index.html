10-second ID: How many resistors touch the base, and does the emitter have a resistor?
  • One resistor VCC→base, emitter at ground → fixed-bias
  • One resistor VCC→base, RE present → emitter-bias
  • Two resistors R1 and R2 on the base → voltage-divider
  • Resistor from collector to base (not from VCC to base) → collector feedback

Three laws used in every DC problem

VBE = 0.7 V (silicon)

Germanium would be 0.3 V. Your exam is Si unless they say otherwise.

IC = β IB

Find IB first. Collector current is beta times that.

IE = (β+1) IB ≈ IC

Use ≈ IC for VE = IE RE unless they insist on (β+1).

Universal IB pattern (this is the whole chapter):
IB = (available voltage − 0.7) / (base resistor + reflected emitter/collector resistors)

Fixed-bias: nothing is reflected. Emitter-bias: RE reflects as (β+1)RE. Voltage-divider exact: RTh is the base resistor, ETh is the available voltage. Collector feedback: RC and RE both reflect as β(RC+RE).

After IB, always the same cleanup

  1. IC = β IB
  2. If there is RE: VCE = VCC − IC(RC + RE). If no RE: VCE = VCC − IC RC
  3. VE = IC RE (0 if no RE). VB = VE + 0.7. VC = VCC − IC RC
  4. VBC = VB − VC. Negative means reverse-biased, which is what you want for the active region.

Chapter 4 — step-by-step for each type

4.3 Fixed-bias · exercises 1, 2, 3, 5

Take from the question

VCC, RB, RC, β. Emitter is grounded, so VE = 0 and VB = 0.7 V.

IB = (VCC − VBE) / RB
IC = β IB
VCE = VCC − IC RC
ICsat = VCC / RC

If they ask VBC: 0.7 − VC. If they give currents/voltages and ask for a missing resistor, invert Ohm’s law.

Worked pattern (same as Ex 4.1)

VCC = 12 V, RB = 240 kΩ, RC = 2.2 kΩ, β = 50

IB = 11.3 / 240k = 47.1 μA
IC = 50 × 47.1 μA = 2.35 mA
VCE = 12 − 2.35×2.2 = 6.83 V
ICsat = 12 / 2.2k = 5.45 mA

IC is about half of sat → safely active. If IC were near ICsat, the transistor is saturating and the linear formulas fail.

4.4 Emitter-bias · exercises 8, 9, 10, 11

Only change from fixed-bias

RE is seen from the base multiplied by (β+1). That is the whole trick.

IB = (VCC − VBE) / [RB + (β+1)RE]
VCE = VCC − IC(RC + RE)
VE = IC RE    VB = VE + 0.7    VC = VCC − IC RC
ICsat = VCC / (RC + RE)

Why they added RE

If β doubles, fixed-bias IC almost doubles. Emitter-bias IC rises much less because IB falls when β rises. Exam line: “which is more stable?” → emitter-bias (and voltage-divider is even better).

Load-line intercepts change too: y-intercept is VCC/(RC+RE), not VCC/RC.

Voltage-divider: exact vs approximate — the difference you must see

Same circuit. Two analysis paths. The exam loves asking you to test the condition, then use the matching path.

The 10× gate

If β RE ≥ 10 R2 → approximate is legal. If not → you must use exact (Thevenin).

Meaning: the resistance looking into the base, about βRE, is so big compared with R2 that almost no current is stolen from the divider. Then IB ≈ 0 and R1–R2 act like a simple unloaded divider.

Exact · always legal

  1. RTh = R1 ∥ R2 = R1 R2 / (R1+R2)
  2. ETh = R2 VCC / (R1+R2)
  3. IB = (ETh − 0.7) / [RTh + (β+1)RE]
  4. IC = β IB, then VCE = VCC − IC(RC+RE)

β is used. Q-point still barely moves when β changes, because RTh is small compared with (β+1)RE.

Approximate · only if 10× holds

  1. VB = R2 VCC / (R1+R2)   (same number as ETh)
  2. VE = VB − 0.7
  3. IE = VE / RE ≈ IC   no IB, no β
  4. VCE = VCC − IC(RC+RE)

Q-point is independent of β. That is why this bias is the exam favorite for “stable against beta.”

4.5 exercises 15, 17, 18, 20, 21, 22 — what each type is

  • 15, 17, 18: full Q-point. Test 10× first. If the figure gives currents already, they may want you to back-solve a resistor.
  • 20: change β and compare. Voltage-divider IC barely moves; that is the point.

4.6 Collector feedback · exercises 27, 29

RF is attached to the collector, not to VCC. Current through RC is IC + IB ≈ IC.

IB = (VCC − VBE) / [RF + β(RC + RE)]
VCE = VCC − IC(RC + RE)

If two feedback resistors with a capacitor to ground between them: for DC the capacitor is open, so RF = RF1 + RF2.

Stability memory

Fixed-bias: IC tracks β one-for-one (worst).
Emitter-bias: better.
Collector feedback: better still, because RC also reflects.
Voltage-divider: best; IC almost independent of β.

Load-line analysis — the two points

A straight line needs two points. The transistor curves are IC vs VCE. The circuit equation is also IC vs VCE. Their crossing is the Q-point.

  1. Point A (cutoff / x-intercept): set IC = 0. Then VCE = VCC. Dot on the VCE axis.
  2. Point B (saturation / y-intercept): set VCE = 0. Then IC = ICsat. Dot on the IC axis.
  3. Draw the straight line A–B. That is the load line.
  4. Find IBQ from the bias formula. The Q-point is where that IB curve hits the line. Read ICQ and VCEQ off the graph.
ConfigPoint APoint B = ICsat
Fixed-biasVCCVCC / RC
Emitter-biasVCCVCC / (RC+RE)
Voltage-dividerVCCVCC / (RC+RE)
Collector feedbackVCCVCC / (RC+RE)

If RC increases, point B drops (line becomes flatter). If VCC decreases, point A slides left. IB moving only slides Q along the same line.

Graph → design (Ex 4.3 style): x-intercept is VCC. y-intercept is ICsat so R = VCC / ICsat (RC or RC+RE). IBQ is the curve through Q. Then invert the IB formula to get RB.

4.11 Design operations · exercises 41, 42, 43

Analysis: parts given, find currents/voltages. Design: Q-point given, find resistors. The master equation is Ohm’s law: R = VR / IR.

41 · Fixed-bias design

  1. If they want VCEQ ≈ VCC/2, then IC RC = VCC/2 so RC = (VCC − VCEQ)/ICQ
  2. IB = ICQ / β
  3. RB = (VCC − 0.7) / IB
  4. Pick nearest standard values

42 · Emitter-stab design

  1. If ICsat given: RC+RE = VCC / ICsat
  2. Often ICQ = ½ ICsat
  3. RC = (VCC − VC)/ICQ or (VCC − VCE − VE)/IC
  4. RE = (VCC/ICsat) − RC
  5. RB = (VCC − 0.7)/IB − (β+1)RE

43 · Voltage-divider design

  1. Rule of thumb: VE ≈ VCC / 10
  2. RE = VE / ICQ
  3. RC = (VCC − VCEQ − VE) / ICQ
  4. VB = VE + 0.7
  5. Choose R2 ≤ β RE / 10 (so approx is valid)
  6. VB = R2 VCC / (R1+R2) → solve R1

Chapter 5 from zero — what this chapter even is

Chapter 4 found the quiet DC point (Q-point): IB, IC, VCE, IE. Nothing is waving. Chapter 5 puts a tiny sine wave on the base and asks three numbers:

Zi

Input impedance

How hard is it to push current into the amplifier? Zi = Vi / Ii. Big Zi is good: the source is not loaded down.

Zo

Output impedance

What does the next stage see looking back? Zo = Vo / Io with the input killed. Small-ish Zo (about RC) is typical here.

Av

Voltage gain

Av = Vo / Vi. For CE it is negative (180° flip). Size is about RC / re, often 100–300.

The only bridge from Ch4 to Ch5:
re = 26 mV / IE
IE is the DC emitter current you already know. If IE = 2.6 mA, re = 10 Ω. That tiny re is why gain is huge: Av ≈ −RC / re.

5.3 How to turn any circuit into the AC picture (exercise 5)

Do this on paper every time. No numbers yet.

  1. VCC becomes a wire to ground. A DC battery does not change with the AC signal, so for AC it is a short. The top of RC and the top of R1 both land on ground.
  2. Every capacitor becomes a short. Coupling C1, C2 and bypass CE all disappear into wires.
  3. Delete what got shorted out. CE is across RE, so RE is gone from the AC drawing. That is the whole point of a bypass capacitor.
  4. Replace the transistor with the re model (next section).

Before · real amplifier

After · AC equivalent

Rin is the only difference: fixed-bias uses RB. Voltage-divider uses R′ = R1 ∥ R2. Output side is identical.

5.4 The re model — the transistor becomes two pieces

Input side (base to emitter): looks like a resistor βre. So the AC base current is simply Ohm’s law:

Ib = Vi / (β re)

Output side (collector to emitter): a current source βIb, plus optional ro in parallel.

Ic = β Ib

Common-base (exercises 6, 7, 10): you look into the emitter, so Zi ≈ re (tiny), and the source is α Ie. No 180° flip.

Typical: βre is a few hundred ohms to ~6 kΩ. ro is ~40–50 kΩ. If the problem does not give ro, treat it as infinite and drop it.

Finding ro from gos (or hoe) — reciprocal math

Datasheets often do not print ro in ohms. They print an output conductance. Conductance is simply “how easily current flows.” Resistance is the opposite, so they are reciprocals.

gos = 1 / ro    and    ro = 1 / gos

Same idea for the hybrid parameter: hoe is also an output admittance in siemens, so ro = 1 / hoe. If the problem says gos, hoe, or yos, treat them the same for this step: invert, watch the μ.

The basic

Ohm’s law is V = I R. Conductance G is defined by I = G V, so G = 1/R. Unit of G is the siemens (S), old name mho.

μ means 10−6. So 20 μS = 20 × 10−6 S.

1 S = 1 / 1 Ω    1 μS = 1 / 1 MΩ

That last line is the exam shortcut: 1 μS ↔ 1 MΩ. Then 20 μS is 20 times easier than 1 μS, so resistance is 20 times smaller than 1 MΩ.

Your notebook example

  1. gos = 1 / ro
  2. ro = 1 / gos
  3. gos = 20 μS
  4. ro = 1 / (20 × 10−6 S)
  5. ro = 50,000 Ω
  6. 50,000 / 1000 = 50 kΩ
Shortcut: ro (kΩ) = 1000 / gos(μS)   →   1000 / 20 = 50 kΩ

Where this number goes

Then RC (and RL if present) go in parallel with this ro. That is why Case 1 asked “is ro ≥ 10 RC?”

After you have 50 kΩ

Test: if RC = 3 kΩ, is 50 kΩ ≥ 10 × 3 kΩ = 30 kΩ? Yes. Ignore ro for Zo and Av.

If they still want the exact value:

Zo = RC ∥ ro = 3 kΩ ∥ 50 kΩ = 2.83 kΩ
Av = − (RC ∥ ro) / re

If gos is not given, and the problem never mentions ro or hoe, treat ro as infinite and skip it.

Catch the question: “gos = 20 μS” or “hoe = 20 μS” is not a new circuit. It is only asking you to make ro first, then use the usual Zi, Zo, Av steps.

Your third page: Case 1 vs Case 2 — this is loaded-amplifier math

Until the last two pages, Vo was taken across RC only. This page adds an extra resistor RL (a speaker, the next stage, a given load). Now collector current must split. That split is current gain Ai. Voltage gain Av is built from the same picture.

What type of math is this? Output current divider + input current divider. You are not inventing a new transistor model. You are asking: of the current βIb, how much actually goes through RL?

The picture that both cases use

Vo = − Ic (ro ∥ RC ∥ RL)

That is the formula at the top of your page: V = Ic (ro ∥ RC ∥ RL), with a minus for CE inversion.

Current divider for Io (through RL only)

Ic hits two lumps: the leftover collector stuff (ro ∥ RC), and the load RL.

Io = Ic × (ro ∥ RC) / [(ro ∥ RC) + RL]

Then Vo = − Io RL (circled on your page). Same voltage, written from the load current.

Case 1 vs Case 2 only changes (ro ∥ RC):

If one of those two is ≥ 10× the other, drop the bigger one from the parallel pair. That is the same 10× club as Zi and Zo.

Case 1 · ro is large

If ro ≥ 10 RC then ro steals almost no current. Ignore ro.

ro ∥ RC ≅ RC
Io = Ic × RC / (RC + RL)

If they also want overall Ai from the source current Ii (RB is in the picture):

Ai = Io / Ii = β × [RB / (RB + (β+1)re)] × [RC / (RC + RL)]

Three pieces: input divider (how much of Ii becomes Ib) × β (Ib to Ic) × output divider (how much of Ic becomes Io). On your notes the last piece was written RC/(ro+RL). That mixes Case 1 with Case 2. For Case 1 the last piece is RC / (RC+RL).

Case 2 · RC is huge or missing

If RC ≫ ro, or RC = ∞, or RB = ∞ then RC steals almost no current. Ignore RC.

ro ∥ RC ≅ ro
Io = Ic × ro / (ro + RL)

If RB is also infinite, all of Ii is Ib, so the input divider is 1:

Ai = β × [ro / (ro + RL)]

That boxed Case 2 formula on your page is this line.

How your page builds Av from the same Io

  1. Definition: Av = Vo / Vi
  2. Vo = − Io RL   (minus = CE inversion)
  3. Io = Ic × (ro∥RC) / [(ro∥RC) + RL]   and Ic = β Ib
  4. So Vo = − β Ib × (ro∥RC) / [(ro∥RC)+RL] × RL
  5. Vi = (β+1) re Ib ≅ β re Ib   (voltage across the transistor input)
  6. Divide. β and Ib cancel. Fast form:
Av = − (ro ∥ RC ∥ RL) / re

No RL on the figure? Then RL is infinite, drop it, and you are back to Av = −(RC∥ro)/re from the earlier pages.

Chapter 5 cheat notes — any math on this syllabus

Every Ch5 number is one of these six jobs. Identify the job, then run the steps. Parallel of two resistors is always R1 R2 / (R1+R2).

The 8-line exam script (do in this order)

  1. Is it a sketch or numbers? Sketch → short caps, ground VCC, drop bypassed RE, draw βre and βIb. Stop.
  2. Identify: one RB = fixed-bias. R1 and R2 = voltage-divider. Input at emitter = common-base.
  3. DC first. Find IE. Fixed: IB = (VCC−0.7)/RB, IE = (β+1)IB. Divider: 10× test, then exact or approx, IE ≈ IC.
  4. re = 26 mV / IE   (IE in amperes, or 26 / IE_mA gives ohms).
  5. βre = β × re. Rin = RB or R1∥R2.
  6. Zi = Rin ∥ βre. Test: if Rin ≥ 10 βre, Zi ≅ βre.
  7. If ro given, test ro ≥ 10 RC. Yes or missing ro → Zo = RC and Av = −RC/re. No → Zo = RC∥ro and Av = −(RC∥ro)/re.
  8. Sanity: re is ohms (often 5–40). |Av| is usually 50–400. Zi is usually under 3 kΩ. Minus sign on Av for CE.

Memory tricks that actually stick

IB song

“Leftover volts over leftover ohms.” Numerator is the supply piece that is not VBE. Denominator is every resistance the base current actually sees, with RE inflated by (β+1).

10× club

If one thing is ≥ 10× the other, drop the bigger parallel partner.

βRE ≥ 10 R2 → approx DC
RB ≥ 10 βre → Zi ≈ βre
ro ≥ 10 RC → Zo ≈ RC and Av ≈ −RC/re

Load line = cutoff + sat

A is “transistor off” (IC=0, whole VCC on the device).
B is “transistor short” (VCE=0, whole VCC on the resistors).

re rhyme

Twenty-six over IE. IE in mA gives re in ohms: 26 mV / 2 mA = 13 Ω. Huge Av because you divide RC by a tiny re.

μS flip

1 μS = 1 MΩ. ro (kΩ) = 1000 / gos(μS). 20 μS → 50 kΩ. 25 μS → 40 kΩ. 10 μS → 100 kΩ.

Units in one second

kΩ × mA = V. μA × kΩ = mV, then convert. If IB comes out in mA, you used kΩ wrong — IB is μA in these circuits.

Caps personality

DC: capacitor = open (blocks DC, isolates stages).
AC: capacitor = short (coupling passes signal; bypass kills RE).

Stability ranking

Fixed (worst) → emitter → collector FB → voltage-divider (best). More resistance reflecting into the base loop → less β sensitivity.

Sign of Av

CE output is inverted → negative Av. If your calculator drops the minus, write it in by hand. CB is not inverted (not on this short list except the model).
