10-second ID: How many resistors touch the base, and does the emitter have a resistor?
  • One resistor VCC→base, emitter at ground → fixed-bias
  • One resistor VCC→base, RE present → emitter-bias
  • Two resistors R1 and R2 on the base → voltage-divider
  • Resistor from collector to base (not from VCC to base) → collector feedback

Three laws used in every DC problem

VBE = 0.7 V (silicon)

Germanium would be 0.3 V. Your exam is Si unless they say otherwise.

IC = β IB

Find IB first. Collector current is beta times that.

IE = (β+1) IB ≈ IC

Use ≈ IC for VE = IE RE unless they insist on (β+1).

Universal IB pattern (this is the whole chapter):
IB = (available voltage − 0.7) / (base resistor + reflected emitter/collector resistors)

Fixed-bias: nothing is reflected. Emitter-bias: RE reflects as (β+1)RE. Voltage-divider exact: RTh is the base resistor, ETh is the available voltage. Collector feedback: RC and RE both reflect as β(RC+RE).

After IB, always the same cleanup

  1. IC = β IB
  2. If there is RE: VCE = VCC − IC(RC + RE). If no RE: VCE = VCC − IC RC
  3. VE = IC RE (0 if no RE). VB = VE + 0.7. VC = VCC − IC RC
  4. VBC = VB − VC. Negative means reverse-biased, which is what you want for the active region.

Chapter 4 — step-by-step for each type

4.3 Fixed-bias · exercises 1, 2, 3, 5

Take from the question

VCC, RB, RC, β. Emitter is grounded, so VE = 0 and VB = 0.7 V.

IB = (VCC − VBE) / RB
IC = β IB
VCE = VCC − IC RC
ICsat = VCC / RC

If they ask VBC: 0.7 − VC. If they give currents/voltages and ask for a missing resistor, invert Ohm’s law.

Worked pattern (same as Ex 4.1)

VCC = 12 V, RB = 240 kΩ, RC = 2.2 kΩ, β = 50

IB = 11.3 / 240k = 47.1 μA
IC = 50 × 47.1 μA = 2.35 mA
VCE = 12 − 2.35×2.2 = 6.83 V
ICsat = 12 / 2.2k = 5.45 mA

IC is about half of sat → safely active. If IC were near ICsat, the transistor is saturating and the linear formulas fail.

4.4 Emitter-bias · exercises 8, 9, 10, 11

Only change from fixed-bias

RE is seen from the base multiplied by (β+1). That is the whole trick.

IB = (VCC − VBE) / [RB + (β+1)RE]
VCE = VCC − IC(RC + RE)
VE = IC RE    VB = VE + 0.7    VC = VCC − IC RC
ICsat = VCC / (RC + RE)

Why they added RE

If β doubles, fixed-bias IC almost doubles. Emitter-bias IC rises much less because IB falls when β rises. Exam line: “which is more stable?” → emitter-bias (and voltage-divider is even better).

Load-line intercepts change too: y-intercept is VCC/(RC+RE), not VCC/RC.

Voltage-divider: exact vs approximate — the difference you must see

Same circuit. Two analysis paths. The exam loves asking you to test the condition, then use the matching path.

The 10× gate

If β RE ≥ 10 R2 → approximate is legal. If not → you must use exact (Thevenin).

Meaning: the resistance looking into the base, about βRE, is so big compared with R2 that almost no current is stolen from the divider. Then IB ≈ 0 and R1–R2 act like a simple unloaded divider.

Exact · always legal

  1. RTh = R1 ∥ R2 = R1 R2 / (R1+R2)
  2. ETh = R2 VCC / (R1+R2)
  3. IB = (ETh − 0.7) / [RTh + (β+1)RE]
  4. IC = β IB, then VCE = VCC − IC(RC+RE)

β is used. Q-point still barely moves when β changes, because RTh is small compared with (β+1)RE.

Approximate · only if 10× holds

  1. VB = R2 VCC / (R1+R2)   (same number as ETh)
  2. VE = VB − 0.7
  3. IE = VE / RE ≈ IC   no IB, no β
  4. VCE = VCC − IC(RC+RE)

Q-point is independent of β. That is why this bias is the exam favorite for “stable against beta.”

4.5 exercises 15, 17, 18, 20, 21, 22 — what each type is

  • 15, 17, 18: full Q-point. Test 10× first. If the figure gives currents already, they may want you to back-solve a resistor.
  • 20: change β and compare. Voltage-divider IC barely moves; that is the point.
  • 21, 22: often “use exact and approx and compare” or load-line / sat on the same CE loop as emitter-bias: ICsat = VCC/(RC+RE).

4.6 Collector feedback · exercises 27, 29

RF is attached to the collector, not to VCC. Current through RC is IC + IB ≈ IC.

IB = (VCC − VBE) / [RF + β(RC + RE)]
VCE = VCC − IC(RC + RE)

If two feedback resistors with a capacitor to ground between them: for DC the capacitor is open, so RF = RF1 + RF2.

Stability memory

Fixed-bias: IC tracks β one-for-one (worst).
Emitter-bias: better.
Collector feedback: better still, because RC also reflects.
Voltage-divider: best; IC almost independent of β.

Load-line analysis — the two points

A straight line needs two points. The transistor curves are IC vs VCE. The circuit equation is also IC vs VCE. Their crossing is the Q-point.

  1. Point A (cutoff / x-intercept): set IC = 0. Then VCE = VCC. Dot on the VCE axis.
  2. Point B (saturation / y-intercept): set VCE = 0. Then IC = ICsat. Dot on the IC axis.
  3. Draw the straight line A–B. That is the load line.
  4. Find IBQ from the bias formula. The Q-point is where that IB curve hits the line. Read ICQ and VCEQ off the graph.
ConfigPoint APoint B = ICsat
Fixed-biasVCCVCC / RC
Emitter-biasVCCVCC / (RC+RE)
Voltage-dividerVCCVCC / (RC+RE)
Collector feedbackVCCVCC / (RC+RE)

If RC increases, point B drops (line becomes flatter). If VCC decreases, point A slides left. IB moving only slides Q along the same line.

Graph → design (Ex 4.3 style): x-intercept is VCC. y-intercept is ICsat so R = VCC / ICsat (RC or RC+RE). IBQ is the curve through Q. Then invert the IB formula to get RB.

4.11 Design operations · exercises 41, 42, 43

Analysis: parts given, find currents/voltages. Design: Q-point given, find resistors. The master equation is Ohm’s law: R = VR / IR.

41 · Fixed-bias design

  1. If they want VCEQ ≈ VCC/2, then IC RC = VCC/2 so RC = (VCC − VCEQ)/ICQ
  2. IB = ICQ / β
  3. RB = (VCC − 0.7) / IB
  4. Pick nearest standard values

42 · Emitter-stab design

  1. If ICsat given: RC+RE = VCC / ICsat
  2. Often ICQ = ½ ICsat
  3. RC = (VCC − VC)/ICQ or (VCC − VCE − VE)/IC
  4. RE = (VCC/ICsat) − RC
  5. RB = (VCC − 0.7)/IB − (β+1)RE

43 · Voltage-divider design

  1. Rule of thumb: VE ≈ VCC / 10
  2. RE = VE / ICQ
  3. RC = (VCC − VCEQ − VE) / ICQ
  4. VB = VE + 0.7
  5. Choose R2 ≤ β RE / 10 (so approx is valid)
  6. VB = R2 VCC / (R1+R2) → solve R1

Chapter 5 — AC in four mechanical steps

5.3 Modeling · exercise 5

A model replaces the transistor symbol with resistors + a controlled source so you can use ordinary circuit laws.

  1. DC sources → short (VCC becomes ground)
  2. Every capacitor → short (coupling and bypass)
  3. Delete parts that got shorted out (a bypassed RE disappears)
  4. Redraw and insert the re model

Why CE bypass kills RE

Exercise 5 is usually: sketch the AC equivalent of a given drawing. No calculator. Just short caps and ground the supplies.

5.4 The re model · exercises 6, 7, 9, 10

re = 26 mV / IE

IE is the DC emitter current from Chapter 4. This is the bridge from DC to AC.

Looking into the base (CE):

Zi,base = (β+1) re ≈ β re

Looking into the emitter (CB):

Zi,emitter ≈ re    (tiny, a few ohms to ~50 Ω)

Output: current source β Ib (CE) or α Ie (CB), optional ro in parallel.

Typical: βre is hundreds of ohms to ~6 kΩ. ro is ~40–50 kΩ. CB input is just re.

5.5 CE fixed-bias AC · exercises 11, 12, 13

  1. DC: IB = (VCC−0.7)/RB, IE ≈ (β+1)IB, re = 26 mV / IE
  2. Zi = RB ∥ βre   ≈ βre if RB ≥ 10 βre
  3. Zo = RC ∥ ro   ≈ RC if ro ≥ 10 RC (or ro = ∞)
  4. Av = −(RC ∥ ro) / re   ≈ −RC / re

The minus sign is a 180° inversion. Exercise 12 style: they give Av and ask for VCC. Work backwards: |Av| = RC/re so re = RC/|Av|, then IE = 26 mV/re, then IB = IE/(β+1), then VCC = IB RB + 0.7.

5.6 Voltage-divider AC · exercises 15, 16, 17

RE is bypassed by CE, so it vanishes from AC. Voltage gain uses the same formula as fixed-bias.

R′ = R1 ∥ R2    Zi = R′ ∥ βre    Zo ≈ RC    Av ≈ −RC / re
The one AC difference vs fixed-bias: Zi includes R1 ∥ R2 instead of RB. Zo and Av are the same shape. Do not forget: you still need a Chapter 4 DC analysis (exact or approx) to get IE before you can find re.

Memory tricks that actually stick

IB song

“Leftover volts over leftover ohms.” Numerator is the supply piece that is not VBE. Denominator is every resistance the base current actually sees, with RE inflated by (β+1).

10× club

If one thing is ≥ 10× the other, drop the bigger parallel partner.

βRE ≥ 10 R2 → approx DC
RB ≥ 10 βre → Zi ≈ βre
ro ≥ 10 RC → Zo ≈ RC and Av ≈ −RC/re

Load line = cutoff + sat

A is “transistor off” (IC=0, whole VCC on the device).
B is “transistor short” (VCE=0, whole VCC on the resistors).

re rhyme

Twenty-six over IE. IE in mA gives re in ohms: 26 mV / 2 mA = 13 Ω. Huge Av because you divide RC by a tiny re.

Units in one second

kΩ × mA = V. μA × kΩ = mV, then convert. If IB comes out in mA, you used kΩ wrong — IB is μA in these circuits.

Caps personality

DC: capacitor = open (blocks DC, isolates stages).
AC: capacitor = short (coupling passes signal; bypass kills RE).

Stability ranking

Fixed (worst) → emitter → collector FB → voltage-divider (best). More resistance reflecting into the base loop → less β sensitivity.

Sign of Av

CE output is inverted → negative Av. If your calculator drops the minus, write it in by hand. CB is not inverted (not on this short list except the model).
